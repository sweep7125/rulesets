# Локальные списки

Эта папка остаётся точкой расширения сборки. Сейчас локальных переопределений нет: категории, включая `nexusmods`, берутся из upstream.

## Добавление категории

Создайте нужную подпапку и файл с именем категории:

```text
data/geosite/my-service
data/geoip/my-network
```

- `geosite/`: по одному домену на строку, например `example.com`. Сборщик создаст правило доменного суффикса — домен вместе с поддоменами.
- `geoip/`: по одному IP, CIDR или диапазону IP на строку. IPv6 сохраняется только для категории `private`.
- Пустые строки и комментарии после `#` игнорируются.
- Результаты публикуются как `geosite/my-service.list` и `geoip/my-network.list` в ветке `sources`; MRS/SRS собираются автоматически.
- Добавление категории не включает её в DAT автоматически: клиентские и серверные DAT используют явно выбранные списки в соответствующих workflow.

**Совпавшее имя полностью заменяет upstream-категорию, а не дополняет её.** Используйте уникальные имена, если переопределение не требуется.

Каждый файл внутри `data/geosite/` и `data/geoip/` считается входным списком. Не кладите туда README, `.gitkeep` или другие служебные файлы. Эта инструкция лежит на уровень выше и не попадает в категории.
